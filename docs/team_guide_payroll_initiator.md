# Payroll Initiator — Your Monday morning in HCM

**Live app:** https://asilhcm.onrender.com  
**Your sidebar badge:** Payroll Initiator

## 1. Sign in
Google sign-in. Role: payroll_initiator.

## 2. First screen
**Payroll Sheet** — monthly payroll grid and adjustments.

## 3. Daily tasks

| # | Task | Where to click |
|---|------|----------------|
| 1 | Run contract payroll | **Payroll Run** → pick contract, month, year → run / review results |
| 2 | Enter or fix employee payroll lines | **Payroll Sheet** → select period → edit rows (before lock) |
| 3 | Process employee claims into payroll | **Claims Queue** → submit/assign claims → ensure status moves toward payroll run |
| 4 | Employee master lookups | **Employee Information** → search employee for bank/CNIC/contract checks |
| 5 | Change requests (HR/policy) | Operations queue — approve/reject via change-request APIs (coordinate with **Operations**) |

## 4. Other modules on your menu
Payroll Run, Employee Information, Claims Queue.

## 5. Escalate to
| Issue | Contact |
|-------|---------|
| Lock payroll for payment | **Finance Approver** |
| Bank payment / HBL file | **AP Team** after lock |
| Contract policy blocks | **Operations** / **Finance Manager** |
