# Finance Manager — Your Monday morning in HCM

**Live app:** https://asilhcm.onrender.com  
**Your sidebar badge:** Finance Manager

## 1. Sign in
1. Open the URL → **Sign in with Google** (work email).
2. If you see **Access Pending**, ask Super Admin to assign inance_manager, then sign out and back in.

## 2. First screen
After login, HCM opens **Payroll Sheet** (first module in your menu). Use the left sidebar to switch modules.

## 3. Daily tasks (pick what applies today)

| # | Task | Where to click |
|---|------|----------------|
| 1 | Review locked payroll months waiting for payment | **Accounts Payable** → **Payroll Queue** tab → expand month → confirm bank transfer when paid |
| 2 | Approve AP payment batches | **Accounts Payable** → **Bills Queue** → items needing Finance Manager approval (API: pending FM approval) |
| 3 | Monitor cash / KPIs | Ask Super Admin for **Managing Director View** access, or use **AR & Collections** for aging |
| 4 | Client / contract tweaks | **Client Information** → select client → business units |
| 5 | Create or adjust team access | **User Management** → **Add User** (email + role) or change role on existing user |

## 4. Modules you normally use
Payroll Sheet, Payroll Run, Bills & Procurement, Invoices (AR), PO Tracking, Accounts Payable, Client Information, Vendor Supplier Master, Annexure Approval, System Configs, User Management, Attendance, Maintenance & CMMS, Intake Hub, Claims Queue, Contract Policies, BD Pipeline, Compliance Ledger, AR & Collections.

## 5. Escalate to
| Issue | Contact |
|-------|---------|
| Payroll lock / unlock, invoice approval | **Finance Approver** |
| Superadmin-only config, deploy, data purge | **Super Admin** |
| Bill approval stuck in procurement | **Procurement Approver** / **Procurement Mgr** |
| Xero push failures on client invoices | **AR Team** (first line) → you if policy decision needed |
